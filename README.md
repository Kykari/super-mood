SUPER MOOD — веб-приложение для ведения дневника настроения с аналитикой.

- Быстрый старт
1. Клонировать репозиторий:
   git clone https://github.com/Kykari/super-mood.git
   cd super-mood
2. Создать файл .env в корне проекта:
   cp .env.example .env
3. Заполнить .env своими данными
4. Запустить сервисы:
   docker-compose up -d
